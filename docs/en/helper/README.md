# Assistant functions

Utility functions exposed by the extension:

* [Column index transform](column-index-number-string-transform.md) — convert between numeric column index and Excel-style letters (e.g. `27 ↔ AA`).
* [Set current line](current_line_set.md) — move the next write position to a later row.
* [Get current line](current_line_get.md) — read the current write position.
* [Get version](get_version.md) — return the installed extension version.
* [Get author](get_author.md) — return author / contact information.
